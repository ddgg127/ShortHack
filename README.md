# ShortHack

«Пульс» — ИИ-помощник для первичного разбора обращений технической поддержки. Он формирует краткое описание, категорию, приоритет, недостающие данные, следующий шаг и черновик ответа.

## Настройка Yandex AI

Скопируйте `.env.example` в `.env` и укажите:

- `YANDEX_API_KEY` — API-ключ сервисного аккаунта с ролью `ai.languageModels.user`;
- `YANDEX_MODEL_URI` — URI модели в формате `gpt://<folder_id>/<model_id>/latest`.

Ключ используется только серверным обработчиком `POST /api/analyze` и не попадает в браузерный JavaScript. Для размещённого сайта эти значения задаются через защищённые переменные окружения Sites.
